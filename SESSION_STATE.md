## Сделано за эту сессию — большой редизайн дашборда
1. **Пульс → факт вместо плана.** 5 плиток: Сварено (т) · Выпущено (шт) · Варок · Реакторов · Ожидает розлива. Убраны План/Факт-выполнение/Статус периода. Починен баг «Ожидает» (варки с закрытым розливом больше не считаются ожидающими).
2. **Плитки → градиентные карточки** с тематичными иконками (бочка/бутыль/колба/ёмкость/песочные часы), мягкие углы/тень, одинаково ярко в обеих темах. Подстрочники без дублирования (средняя варка · SKU · завершено · свободно · варок).
3. **Пикер периода** вместо День/Неделя/Месяц: пресеты **Сегодня / 7 дней / 30 дней / 90 дней** + произвольный **С…По** («Применить»), стрелки ‹ › сдвигают окно на его длину. `state.dashPreset` + переписан `dashRange()`. Заголовок «Дашборд» и пикер — в одну строку, пикер справа.
4. **Единые заголовки блоков** (цветная метка + название слева, бейдж справа, разделительная линия).
5. **Убраны** блоки «Выпуск по дням» и «Тренд за месяц» + вычищен их мёртвый код.
6. **Логичные названия** блоков.
7. **`.nojekyll`** — чтобы сборки Pages были стабильнее (гоняли статику через Jekyll → падало).
8. **Детальный слой — 5 премиум-блоков в порядке плиток** (единый стиль `.db-*`: иконки-чипы, подсветка акцентом, градиентные графики, анимация):
   - **Сварено — по продуктам** (градиентные бары, кг).
   - **Выпущено — по продуктам** (кольцо/donut по SKU + бары по линиям розлива).
   - **Варки — адаптивный**: «Сегодня» → живой конвейер по стадиям (В очереди·Варится·Сварено·На розливе·Готово); «7/30/90 дней» → накопительно (Всего·Завершено·В работе) + столбики варок по дням.
   - **Загрузка реакторов** — танки-гейджи (доля выполненного = выпущено/сварено).
   - **Ожидает розлива** — задержки (что застряло, сколько ждёт, просрочка >24ч красным, помечено «на сейчас»).

**Логика данных (зафиксирована с пользователем):** верх = оперативный слой (быстрый взгляд), низ = детальный разбор той же темы, в том же порядке. Накопительные показатели (Сварено/Выпущено/Линии/Реакторы) корректны за любой период; моментальные (стадии варок, «сколько ждёт») — про «сейчас», поэтому «Варки» сделан адаптивным под период.
