# Уровень 4 «Горизонты» — переключатель День/Неделя/Месяц

Источник: ТЗ §7 «Горизонты контроля» + DASHBOARD_PROGRESS.md.
Единый переключатель вверху, применяется ко ВСЕМ блокам. Заменяет фильтр 7/30/90.

## Решение (v1)
- Горизонт задаёт временное окно [start,end] от якорной даты `state.dashDate`:
  День = [d,d]; Неделя = Пн–Вс; Месяц = 1-е…послед. число.
- `state.dashHorizon` ('day'|'week'|'month'), по умолчанию 'day' (сброс при загрузке, как biPeriodDays).
- Все блоки считают по этому окну. День — live-семантика (как сейчас); Неделя/Месяц — агрегаты.
- Богатые тренд-визуалы (лучший день, тренд-линия месяца) — следующий спринт (так и в ТЗ §10, п.9).
