# Уровень 3 «Продукты» — таблица по SKU

Источник: DASHBOARD_PROGRESS.md + ТЗ_Дашборд_ВарКа_CRM.md (§6).

## Что делаем
Таблица группировки завершённых варок по SKU за выбранный период. Заменяет блок
«Выполнение плана» (`#bi-deviation-list`). Колонки:
Продукт (SKU) · Варок · Выпущено (кг/шт) · % от итога · Реакторы + строка ИТОГО.

## Решения (из согласованного ТЗ/прогресса)
- База доли — ОБЪЁМ (кг), тара-нейтрально; штуки показываем рядом.
- Только `status === 'done'`; период = state.dashDate + state.biPeriodDays (как в renderBiAnalytics).
- Сортировка по выпуску (кг) DESC. Бейджи реакторов — цвета `--r1..8` через reactorColor().
- Пусто → dash-empty (как у соседних блоков).
