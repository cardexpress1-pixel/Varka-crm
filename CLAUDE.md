# CLAUDE.md — правила проекта VarKa

## Источник истины и деплой
- **Рабочая копия и источник истины — ЭТОТ репозиторий:** `Desktop/CRM/проект VarKa`
  (remote `origin` = `github.com/cardexpress1-pixel/Varka-crm`, ветка `main`, хостинг GitHub Pages → `cardexpress1-pixel.github.io/Varka-crm/`).
- **НЕ работать в `Desktop/VarKa`** — это устаревшая копия, не подключённая к git. Все правки — только здесь.
- **Деплой:** правка `index.html` → `git commit` → `git push origin main` → GitHub Pages пересобирает сайт. Боевой сайт = `origin/main`.
- **`git push` / публикация — ТОЛЬКО с явным подтверждением пользователя («go»).** Перед пушем показать: репозиторий, remote, ветку, `git status`, изменённые файлы, краткий diff.

## Работа с данными (Firestore) — критично
- Приложение подключено к **ЖИВОМУ** Firebase/Firestore: всё состояние в одном документе `varka/state` (поле `_rev`). **В приложении нет резервного копирования.**
- **НИКОГДА не запускать/проверять приложение способом, который может вызвать запись в боевую БД.** Записью считать не только явный save, но и любые обработчики, дергающие `saveState()` внутри: смена темы (`toggleTheme`), навигация, клики.
- Проверять только на **изолированной копии**: обнулить Firebase-конфиг, или запускать офлайн, или подставить мок-стейт. Никогда — поверх живого документа.
- **Любая запись в общий/внешний ресурс (Firestore, git push) — только с явного согласия пользователя.**
